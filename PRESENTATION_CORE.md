# OrbitGuard — Presentation Core

## One-line pitch

**OrbitGuard is an explainable space-situational-awareness platform that turns public orbital data into searchable, visual, and historically trackable conjunction risks.**

## Problem

LEO contains many active satellites and debris objects. Raw orbital element data is difficult for a non-specialist to interpret, while a close-approach workflow needs propagation, screening, refinement, prioritization, and visualization.

## Solution

OrbitGuard combines:

1. OMM/GP ingestion
2. SGP4 propagation
3. Multi-object conjunction screening
4. Closest-approach refinement
5. Explainable prioritization
6. Historical encounter tracking
7. Interactive 3D visualization

## Differentiator

**Explainability + continuity:** each flagged encounter has a visible "why" breakdown and can be compared across repeated orbital-data updates.

## Technical honesty

The MVP is a screening/prioritization system, not an operational collision-probability or maneuver system. This distinction should be stated explicitly in the PPT and demo.
